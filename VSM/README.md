# Value Stream Maps

The portal's Value Stream Maps page is `value-stream-maps.html`.
Media links are configured in `js/vsm.js`. Add the Intermediate and Future
State videos and PDFs to their respective folders, then replace the matching
`null` entries with repository-relative file paths to enable their buttons.

The original Current State video is retained locally and excluded from Git
because it exceeds GitHub's per-file limit. The portal publishes the optimized
`Current state VSM/current-state-web.mp4` copy instead.
